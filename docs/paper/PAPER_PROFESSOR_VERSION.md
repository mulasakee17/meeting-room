## 摘要

大语言模型（LLM）多智能体系统在协作决策中面临回声室效应、权威偏差、群体极化等集体失败风险，而现有治理工具聚焦于安全层，缺乏对认知层偏差的运行时检测手段。MAST 分类体系虽标注了多智能体系统 14 种失败模式，但明确将检测与干预列为未来工作。针对这一空白，本文提出 v6 认知治理系统：让 LLM 直接输出**五维认知状态**（效用、证据、确信度、惯性、易感性），通过**一致性诊断**（δ 信号，检测"自报 vs 行为"之间的矛盾，无需 ground truth）识别群体认知异常，并以**非破坏性干预**（改变信息流而非信念权重）实施治理，同时以解耦的**社会热力学测量**（$F=U-T\cdot H$，复合失序指标 CDI）提供集体状态信号。系统采用分层成本架构：确定性数学处理绝大多数轮次（设计目标约 95%，零额外 LLM 调用），LLM 仅在异常轮次作为语义传感器兜底。历史方法学验证（169 次闭环实验）表明共识与决策质量几乎不相关（$r\approx-0.10$，$p=0.20$，不显著，探索性），结构重排优于过程治理（$d=1.44$），破坏性干预有害（$\Delta\tau=-0.267$）；v6 Pilot 验证了"δ→干预"链路（16 次干预，$\tau=0.643$ vs 基线 $0.571$）。

## 1. 背景介绍

大语言模型（LLM）驱动的多智能体系统，如 AutoGen[1]、CrewAI、LangGraph 等框架，正在越来越多地被用于协调多个智能体完成复杂的协作决策任务。在群体讨论过程中，这些系统继承了社会心理学长期研究的集体失败模式：回声室效应（echo chamber，信息环境同质化导致观点自我强化）、权威偏差（authority bias，少数高权威智能体主导意见）、群体极化（group polarization，讨论使群体立场走向极端）以及过早共识（premature consensus，在信息未充分交换前就达成一致）。

多智能体失败模式已有系统化的描述性研究。Cemri 等提出的 MAST 分类体系从七个框架的 1600 余条对话轨迹中标注了 14 种失败模式，其中智能体间对齐失败是最大的单一类别（占 32.3%）[2]，但该工作明确将**检测与干预**列为未来工作。与此同时，生产级治理工具——如 OWASP Agentic Top 10[3]、微软 Agent Governance Toolkit、NVIDIA OpenShell——聚焦于安全边界（未授权工具调用、预算超限、提示注入），属于安全层防护，而非认知层治理。

本文所指的"认知治理"是一个更内层的问题：**在讨论进行过程中，检测群体是否正在滑向偏差性共识，并在适当时机施加干预以纠正认知方向**。这一层在学术分类和生产工具中均未得到解决。MAST 是描述性的（标注"发生了什么"），而本文的目标是将其可操作化（检测"正在发生什么"并施加"做什么"）。

针对上述空白，本文提出 **v6 认知治理系统**，其核心设计决策与已有工作的差异体现在三个方面：

1. **状态表示**：不依赖单一标量 belief，而是让 LLM 直接输出五维认知状态——消除"系统从行为反推认知"的循环论证。
2. **检测方式**：用**一致性诊断**（对比可观测信号之间的矛盾）替代启发式阈值判断——无需 ground truth。
3. **干预原则**：改变信息流而非信念权重——避免破坏性干预的级联反火。

**测量优先的设计哲学**：历史数据提供了质疑"收敛即正确"假设的证据（$r\approx-0.10$，见 §4.1）。若共识与决策质量几乎不相关，那么只优化共识的治理系统可能是在优化错误目标。因此，**没有可靠的测量信号，干预就是盲目的**——这构成了本文"测量优先，治理在后"的方法学基础。

## 2. 相关研究

本文的工作涉及三个相互衔接的技术领域：观点动力学的统计物理建模（§2.1）、多智能体偏差检测与失败分类（§2.2）、以及多智能体认知状态与发言选择机制（§2.3）。这三个领域分别对应本文系统设计的三个层次：**群体状态建模**（如何刻画集体认知）、**异常检测**（如何识别认知偏差）、**认知状态表示**（如何让智能体暴露其内部判断过程）。

### 2.1 观点动力学的统计物理建模

将统计物理模型应用于观点动力学已有较长的研究历史。Pluchino 等（2004）首次将 Kuramoto 模型适配到观点动力学中[4]，用相位同步刻画群体观点的对齐程度；Pradhan 和 Ujjwal（2025）进一步发现该模型的变体在双极化和共识之间存在爆炸性相变[5]。这些工作支撑了本文基于共识序参量 $R$ 的群体同步检测设计。

在热力学概念的迁移应用方面，López-Corona 等将 Helmholtz 自由能应用于社会合作分析[6]，Tomé 等将观点形成纳入随机热力学框架[7]，Galam 通过零温 Ising 模型分析回声室与随机极化[8]，Tsekov 则系统提出"社会热力学"的框架[9]。

上述工作的共同特征是**将相变量视为描述性量**——它们描述了群体状态的数学性质，但未连接到可部署的运行时检测-干预闭环。本文的差异在于：（i）将相变量工程化为闭环"检测→干预→评估"周期中的集体状态信号；（ii）基于五维认知状态向量而非单一标量信念计算，实现变量的解耦（见 §3.6）。

### 2.2 多智能体偏差检测与失败分类

多智能体系统的失败分类已有描述性框架。MAST 分类体系标注了 14 种失败模式，其中智能体间对齐失败（信息隐瞒、输入被忽略、推理-行动不匹配）是最大类别，但未提供运行时检测方法[2]。

在认知偏差的编程与测量方面，Liu 等的 CoBRA 工作发现：自然语言描述无法跨模型一致地控制偏差[10]，这促使本文采用**数学化、可解释的检测指标**而非依赖 LLM 文本判断；Nudo 等发现 LLM 智能体会系统性放大极化信号的"生成性夸张"[11]。

在共识与决策质量的关系方面，Du 等引入多智能体辩论（Multi-Agent Debate）并隐含了"共识收敛即正确"的范式[12]。本文的历史观测（$r\approx-0.10$，$p=0.20$，不显著，探索性）**质疑**了该假设的普适性。Cui 等的 Free-MAD 独立质疑了"共识=正确性"[13]，Riedl 的 PID 框架为基于序参量的共识度量局限提供了替代视角[14]。Jin 等量化了权威偏差占决策方差的 37.1%[15]，Liang 等发现思维退化（Degeneration-of-Thought）现象[16]。这些工作共同说明：**偏差检测需要不依赖单一标量的多信号一致性分析**，这正是本文 δ 诊断的出发点。

### 2.3 认知状态与发言选择机制

多智能体讨论的发言选择是一个独立研究问题。AutoGen 的 SelectorGroupChat 使用集中式 LLM 选择器（每轮一次额外 LLM 调用）[1]，LangChain 采用去中心化竞价机制。

在认知状态暴露方面，Yang 等的 Think-Before-Speak（TBS）框架通过编排器协调智能体的意图表达[17]，而本文的 v6 路径让 LLM **直接输出结构化的认知状态**（效用向量、证据覆盖、确信度等），无需编排器中转。本文历史路径提出的五因子发言意愿公式（完全去中心化、闭式可分析、零额外 LLM 成本）是该方向的贡献之一，但在 v6 主线中发言选择不是核心——v6 采用同步固定轮次，聚焦于治理而非发言机制。

## 3. 系统设计：v6 认知治理系统

### 3.1 总体架构

SwarmAlpha v6 实现五阶段闭环：**观察 → 建模 → 检测 → 干预 → 评估**。与早期版本（标量 belief + 规则检测器）不同，v6 的核心流程为：

```
LLM（感知）→ 五维认知状态 → δ 一致性诊断 → 非破坏性干预 → 热力学测量
     ↑                                                          ↓
     └──────────────── LLM 语义传感器（SemanticTool，可选） ←────┘
```

系统采用**分层成本架构**：
- **确定性优先**：设计目标约 95% 轮次的检测/治理由确定性数学处理（零额外 LLM 调用；实际触发率待 E9 全量实测）。
- **LLM 兜底**：仅在 δ 诊断的异常轮次，触发 SemanticTool（LLM 作为语义传感器，非决策者），执行证据语义去重、信息缺口分析和干预文本生成。

### 3.2 五维认知状态表示

让 LLM 直接输出五维认知状态，系统只计算其中两维（惯性、易感性）：

| 维度 | 符号 | 来源 | 含义 |
|------|------|------|------|
| 效用 | $U$ | LLM 原生输出 | 对候选选项的偏好向量 |
| 证据 | $E$ | LLM 原生输出（覆盖度/质量）+ 系统推导（多样性） | 证据覆盖度/质量/多样性 |
| 确信度 | $C$ | LLM 原生输出 | 自报确信度（0-100） |
| 惯性 | $I$ | 系统计算 | 认知改变的阻力（角色+反驳+衰减） |
| 易感性 | $\Lambda$ | 系统计算 | $\max((1-I)(1-C), 0.05)$，暴露后响应概率 |

**设计动机**：早期版本让 LLM 输出 belief/confidence，系统从行为 post-hoc 反推认知状态——存在循环论证（用一个模型自己的输出解释同一个模型的行为）。v6 让 LLM **直接自报**效用、证据覆盖度、证据质量、确信度，系统计算惯性、易感性以及证据多样性（从证据类别数推导）——**减少但未完全消除系统后处理**（实际系统计算 3 项：惯性、易感性、证据多样性）。

#### 3.3.2 δ 一致性诊断信号阈值（`computeDelta.ts`）

δ 诊断层采用**自适应阈值**：`effective = base + (1 − minConfidence) × safetyMargin`——群体置信度越低，阈值越保守（防止在弱信号上误报）。

| δ 信号 | base 阈值 | 安全边际 | 检测的矛盾 |
|--------|-----------|----------|-----------|
| $\delta_{polarization}$ | 0.15 | 0.05 | 效用向量分化严重 |
| $\delta_{1D\_mask}$ | 0.40 | 0.05 | 标量共识掩盖向量分歧 |
| $\delta_{evidence\_silence}$ | 0.50 | 0.05 | 证据被系统性忽视 |
| $\delta_{confidence\_gap}$ | 0.60 | 0.20 | 自报高确信但效用偏离群体 |
| $\delta_{stance\_flip}$ | 0（二进制） | 0.10 | 立场翻转（触发即报警） |
| $\delta_{no\_response}$ | 0（二进制） | 0.40 | 干预后无响应（触发即报警） |
| $\delta_{concentration}$ | 2.0 | 0.40 | 惯性过度集中 |
| $\delta_{consistency}$ | 2.0 | 0.35 | 立场变化与惯性矛盾 |

注：二进制信号（stance_flip、no_response）base=0，不通过阈值调灵敏度，而是通过**可用性门控**（数据不足时直接不触发）。

### 3.4 δ 一致性诊断原理与公式（教授要求 ②）

#### 3.4.1 设计原理

传统检测器需要定义"什么是异常"（需要 ground truth，如"共识水平应 > 0.8"）。v6 的 δ 诊断采用**矛盾检测**：不需要知道"正确行为"是什么，只需检测可观测信号之间的**不一致**。其理论依据是：健康的认知过程应表现出多信号一致性——自报确信度高的智能体，其效用向量不应大幅偏离群体；标量共识高时，向量层面不应存在显著分歧。一旦多个独立信号出现矛盾，即存在认知异常，且**矛盾本身是可验证的证据**（区别于不可验证的先验阈值）。

#### 3.4.2 主要公式

**δ 自适应阈值**（`computeDelta.ts`）：

$$ \text{effective}_k = \text{base}_k + (1 - \min_j c_j) \cdot \text{safetyMargin}_k $$

其中 $c_j$ 为智能体 $j$ 的自报确信度（归一化到 [0,1]），$\min_j c_j$ 为群体最低确信度。高确信度 → 阈值接近 base → 灵敏；低确信度 → 阈值向 base+safetyMargin 移动 → 保守。

**惯性计算**（`cognitiveState.ts`）：

$$ I_i = \text{clip}\Big(0.7\cdot I^{role}_i + 0.2\cdot I^{evid}_i + 0.1\cdot I^{expr}_i - n^{refute}_i \cdot 0.1,\ 0.05,\ 0.95\Big) \times 0.98 $$

其中 $I^{role}_i$ 由角色映射（专家 0.6 … 新手 0.3），$I^{evid}_i = \text{coverage}\times 0.3$ 为证据基础，$I^{expr}_i$ 为表达加成（每发言一次 +0.05，上限 1），$n^{refute}_i$ 为近期被反驳次数。

**易感性（DeGroot 更新系数）**（`cognitiveState.ts`）：

$$ \lambda_i = \max\big((1 - I_i)(1 - c_i),\ 0.05\big) $$

其中 $c_i$ 为智能体 $i$ 的确信度。易感性控制智能体在群体影响下的更新幅度：惯性大或确信度高的智能体更新幅度小。

**社会热力学变量**（v6，`MeasurementLayer.ts`）：

| 变量 | 公式 | 含义 |
|------|------|------|
| $R$ | $(\overline{\text{cos}}(\mathbf{u}_i,\mathbf{u}_j) + 1)/2$ | 效用向量两两余弦均值归一化，群体对齐度 |
| $T$ | $\frac{1}{n}\sum_i \frac{\|\mathbf{u}_i(t)-\mathbf{u}_i(t-1)\|}{2\sqrt{K}}$ | 效用向量逐轮 L2 波动，归一化温度 |
| $H$ | $-\sum_k p_k \log_2 p_k$（归一化） | 证据 supports 分布熵 |
| $F$ | $U - T\cdot H$ | 复合失序指标 CDI（$U$=平均效用 L2 范数） |

**理论依据**：$F=U-T\cdot H$ 的形式借鉴统计物理的 Helmholtz 自由能 $F=U-TS$，但 $U$（效用强度）、$T$（波动）、$H$（熵）均为**工程定义、无量纲**——明确不声称是热力学物理量，仅作为压缩三维度到单标量的工程诊断指标。其理论价值在于：v6 中 $U/T/H$ 来自不同信息源（总能量/时序/分布），实证解耦（$r(U, T\cdot H)=-0.274$，见 §4.4），修复了旧公式 $F=(1-R)+T\cdot H$ 的双重计数问题（旧公式 $r=0.9175$，$R/T/H$ 同源自标量 belief，退化为 1 个有效维度）。

### 3.5 非破坏性干预

基于历史破坏性干预（`reduce_weight`、`force_reflection`）实测有害（$\Delta\tau=-0.267$，见 §4.1）的教训，v6 采用改变**信息流**而非**信念权重**的干预原则：

| 干预 | 机制 | 改变什么 |
|------|------|----------|
| **inject_evidence** | 向讨论注入被忽略的私有证据 | 信息流向 |
| **rebalance_attention** | 调整发言顺序，让被忽视的智能体先发言 | 发言顺序 |
| **shuffle_knowledge** | 结构性重排知识（历史最强干预，$d=1.44$） | 知识分配 |

**设计原则**：干预应改变信息流向，而非信念权重。压制持有关键信息的智能体（reduce_weight）导致信息丢失，打断自然收敛的反思（force_reflection）对立场固化智能体反而强化其立场。

**证据状态**：⚠️ 设计方向由历史失败支持；v2.1 干预尚无统计验证（smoke test $N=6$，$\Delta\tau=0.000$，早期 +0.533 已撤回）。

### 3.6 热力学测量与解耦

**旧定义**（历史，已废弃）：$F=(1-R)+T\cdot H$，其中 $R$ 为 Kuramoto 序参量、$T$ 为 belief 总体标准差、$H$ 为 belief 5-bin Shannon 熵。

**实证证伪（2026-07-28）**：旧 $F$ 两分量强相关 $r=0.9175$，且 $R/T/H$ 由回归 $F\approx0.019+2.014(1-R)$（$R^2=0.955$）显示退化为 1 个有效维度——旧标量 belief 路径下三个"热力学变量"是同一底层量的不同变换。

**v6 修正**：基于五维认知状态向量，改用 $F = U - T\cdot H$。$U$ 与 $T\cdot H$ 乘积解耦（$|r|=0.274$），相较旧路径 $r=0.917$ 大幅改善。但需诚实标注：**$U$ 与 $H$ 分量间仍有耦合（$r=-0.79$）——解耦是部分的，非完全独立**。

**命名降级（2026-08-02）**：$F$ 更名为**复合失序指标（Composite Disorder Index, CDI）**，明确不声称热力学物理量，仅作为工程诊断指标。

### 3.7 历史路径（对比基准）

早期版本的两项贡献在当前 v6 主线中降级为历史/对比基准：

- **七种偏差检测器**（4 经典 + 3 MAST 对齐）：
  - **4 经典检测器**（belief 基，触发阈值）：回声室（信息冗余 ≥ 0.5）、权威偏差（引用集中度 ≥ 0.25）、极化（信念双峰分布 ≥ 0.30）、过早共识（轮次浅 + 共识高 ≥ 0.35）。
  - **3 MAST 对齐检测器**：FM-2.4 信息隐瞒、FM-2.5 输入忽视、FM-2.6 推理-行为不匹配——已实现并通过单元测试，但 0 次实证触发（"实现+单元测试"级贡献）。
- **五因子发言意愿公式**：异步路径（asyncEngine，已冻结）的历史贡献，v6 同步路径不使用。

## 4. 实验与结果（教授要求 ③）

### 4.1 实验任务定义

本文在两个隐蔽信息（hidden-profile）任务上开展实验。两个任务结构相同：5 个候选选项 × 5 个维度，每个智能体独占一个维度的原始数据，任何单一维度都不能独立决定排序——正确答案需要跨维度加权综合。两个任务的核心张力都是**"表面最优" vs "真实最优"**：一个在 3 个低权重维度领先的候选看似最优，但在 2 个高权重维度垫底。

- **锚定**：市长指示"速度是最高优先级"，但速度权重仅 0.10（刻意误导）。

## 5. 总结与展望

### 5.1 工作总结

本文设计并实现了一套基于社会热力学与认知状态一致性诊断的 LLM 多智能体认知治理系统，围绕"测量优先，治理在后"的方法学展开，主要贡献如下：

1. **状态表示**：让 LLM 直接输出五维认知状态（效用、证据、确信度、惯性、易感性），消除循环论证，为检测提供结构化输入。
2. **检测方法**：提出 δ 一致性诊断——通过对比可观测信号之间的矛盾识别认知异常，无需 ground truth；采用自适应阈值（置信度越低越保守）。
3. **干预原则**：确立"改变信息流而非信念权重"的非破坏性干预方向，避免破坏性干预的级联反火。
4. **测量框架**：基于认知状态向量重新定义社会热力学变量（$F=U-T\cdot H$），实证解耦（$r=0.917\to -0.274$），修复旧公式的双重计数问题，并诚实降级为工程诊断指标 CDI。
5. **实证发现**：169 次闭环实验确立了"共识≠正确"（$r\approx-0.10$）、结构重排优于过程治理（$d=1.44$）、破坏性干预有害（$\Delta\tau=-0.267$）三个发现。

### 5.2 经验与局限

- **天花板效应**：Supplier 任务基线 τ=0.68，治理提升有限（d=0.47 不显著）；治理在困难任务（Crisis，基线 τ=0.41）上显著有效（d=0.92）——**治理的价值在困难任务上体现，简单任务上可能反而无益甚至有害**。
- **单模型限制**：历史 169 闭环实验全在 DeepSeek-V3 上完成；跨模型 pilot 被代码版本混杂（F16 降级）。跨模型验证是下一步优先事项。
- **证据分层**：历史证据（169 闭环）与 v6 证据（仅 Pilot）来自不同代码版本，论文不以历史证据冒充 v6 证据。
- **解耦不彻底**：$U$ 与 $H$ 分量间仍有耦合（$r=-0.79$），解耦是部分的。
- **3 个 MAST 检测器 0 实证触发**：实现完成但缺乏触发场景验证。

### 5.3 展望

1. **E9 全量实验**：完成 200 runs 四组对照（A 无治理 / B δ 治理 / C δ+SemanticTool / D 旧检测器），对 B−A 主比较（δ 治理效果）进行正式统计检验。
2. **跨模型验证**：同代码版本下用 Qwen、Zhipu 等模型重复实验，验证发现的可泛化性。
3. **第三任务**：增加任务多样性（当前 2 个历史任务 + 1 个 v6 任务）。
4. **检测器实证标定**：构造触发场景验证 3 个 MAST 检测器（FM-2.4/2.5/2.6）。
5. **理论形式化**：推进命题证明（8 个中 4 个已证，4 个为猜想），将 δ 检测的证据性与自适应阈值从工程启发式提升为可证明的检测理论。
