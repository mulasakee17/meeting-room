# 原稿逻辑图

## 原稿主线

旧稿把多智能体讨论理解为一个可由“社会热力学”刻画的动力系统，依次提出个体状态、群体状态、检测指标、干预策略和实验结果。其优点是问题意识强：共识可能是错误收敛，影响分布和信息流应被治理；其主要缺口是若干状态量来自 LLM 自报或任务特定启发式，却在缺少测量效度与因果识别的情况下被提升为通用认知状态和控制信号。

## 原稿单元与处理决定

| 原稿单元 | 原功能 | 当前证据问题 | 新稿处理 |
|---|---|---|---|
| 多 Agent 会产生错误共识 | 建立问题 | 方向成立，但不能由旧实验数字泛化 | 保留为动机，以 MAD、HiddenBench、从众研究支撑 |
| R/T/H/F 与社会温度 | 给出统一状态 | 量的来源、自报/派生边界与跨任务意义不稳定 | 降级为历史探索；不用作近期控制变量 |
| 共识、影响 Gini、传播 | 描述群体动力 | 描述量不能替代决策质量或因果影响 | 保留为 secondary mediator，明确权限边界 |
| ForceReflection、shuffle 等干预 | 展示治理 | 旧协议、预算和结果口径不足以支撑通用治理效果 | 作为候选治理家族与历史启发，不进入主结论 |
| 社会热力学 | 提升理论上限 | 尚无宏观态预测、响应与缩放证据 | 保留为 ST-1 至 ST-4 长期研究纲领 |
| 416 次历史实验 | 提供实证 | 与当前 authority/schema/measurement contract 不同 | 只作历史线索；当前结果以 80-run V6 artifact 为准 |

## 新稿控制逻辑

新稿不再从“宏观理论—若干量—治理有效”顺推，而从最小可证伪链条反推：若一个量会触发治理，首先必须说明它如何被提示词诱导、如何解析、对无关扰动是否稳定、对已知证据是否响应、能否预测独立结果；随后才能验证 detector，最后才能随机评估治理行动。社会热力学与异构智能治理保留，但不竞争近期论文的唯一主贡献。
