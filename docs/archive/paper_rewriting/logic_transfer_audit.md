# 逻辑迁移审计

## 已保留的设计哲学

1. 多智能体的主要风险不仅是单点错误，而是错误如何经交流、身份、来源相关性和共识形成被放大。
2. 治理对象包括信息访问、验证资源、影响力和停止决策，而非只修改一句 prompt。
3. 共识、影响分布和传播结构值得记录，但它们是中介/描述量，不能替代独立决策质量。
4. 负结果与失败态必须显式保留；不能用重试、补样本或事后改阈值擦除。
5. 社会热力学作为统一宏观理论仍保留，但必须从可审计微观状态逐级获得证据。

## 已纠正的逻辑跳跃

- “LLM 输出 confidence”不再推出“读到内心信念”。
- “公式可算/replay 通过”不再推出“测量有效”。
- “检测到高 confidence/低 lineage”不再推出“应当干预”。
- “投递 verification”不再推出“agent 接受或 outcome 改善”。
- “apply--holdout 的差异”不再推出“verdict 标签本身有效”：当前 apply 同时带来 task-conditioned re-analysis 与解释文本，sham 只提供受限过程控制。
- “候选规则被用于随机机制实验”不再推出“候选规则已经是有效 detector 或可部署 controller”。
- “共识增加/影响更均匀”不再推出“治理质量提高”。
- “异构模型协作”不再被当作独立新颖性。

## 前后呼应检查

引言提出的三个承诺分别由方法资格链、80-run 可重放示范、原始批次 DEFER 与 fresh-identity 续跑的受限探索性信号响应；task-held-out replication 被明确标为未来 DESIGN INTENT。讨论中的异构治理与社会热力学均明确依赖未来证据，不反向抬高摘要和结论。
