# 已确认的论文动机

## 控制动机

多智能体 LLM 在信息分散的任务上会形成**假共识**——群体重复同几条证据、达成一致、然后一起自信地错（HiddenBench 报告准确率掉到 ~30%）。已有方法（MAD 辩论、证据交换）通常问"该不该披露信息"，却把"披露哪一类信息"当作不言自明。

本文的控制动机是一个更细、且可被冻结随机对照检验的问题：

> 在群体高分歧时，向群体披露**证实证据（每个立场为何正确）**，还是**证伪证据（其他选项为何错误）**，更能改善最终决策质量？

这一问之所以非显然：LLM 在讨论里本就同时产出 supports 和 attacks 两类证据，而常见的"证据交换"实现只取 supports——恰好系统性丢弃了能打破假共识的那一半。

## 用户确认的写作重点

论文必须：

1. 把披露方向（supports vs attacks）写成**事先冻结的随机对照臂**，而不是 bug 修复叙事；
2. 报告两组在同一触发条件、同一任务集、同一臂分配下的 Brier 与准确率；
3. 用逐场回溯证明"证伪证据本就存在于 round-1，被 supports-only 过滤器丢弃"（机制证据，不是修辞）；
4. 报告真相盲假共识探测器（证据复用率）的总相关与任务内相关，明确它与"简单任务高复用"的边界；
5. 诚实写语义墙：真相盲探测器测的是"证据耦合/复用"，不是"对错"；
6. 把所有数字锚定在结果文档，不发明数据。

## 后续定位

- 跨模型（Qwen/GLM）、跨任务族、更大 n 是投稿前的补强，不在本文范围内；
- "部分暴露协议 / 耦合度测量"是第二篇或后续工作；
- 不预设治理有效；治理是本文的被测对象。
