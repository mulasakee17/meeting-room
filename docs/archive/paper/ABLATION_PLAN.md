# 超参数敏感性 / 消融实验方案（回应"魔法数字过拟合"质疑）

> 目的：证明系统性能**不过度依赖**任意设定的启发式参数，回应审稿人"过度拟合到启发式"的质疑。
> 状态：方案设计（2026-08-02），待 DeepSeek 充值后执行。
> 原则：每次消融只改变**一个**参数，固定任务/seed/其余参数，保证可归因。

---

## 1. 要消融的超参数（按影响优先级）

| 参数 | 基线值 | 消融值 | 影响面 |
|------|--------|--------|--------|
| **Inertia 权重**（cognitiveState） | 0.7·role + 0.2·evidence + 0.1·expr | 0.5/0.3/0.2、0.9/0.05/0.05 | v6 认知状态 |
| **Inertia 衰减** | 0.98 | 0.95 / 0.99 | 认知惯性 |
| **REDUCE_WEIGHT_FACTOR** | 0.5 | 0.3 / 0.7 | 干预强度 |
| **REFLECTION_FACTOR** | 0.2 | 0.1 / 0.4 | 干预强度 |
| **检测器阈值**（回声室） | 0.5 | 0.4 / 0.6 | 检测灵敏度 |
| **检测器阈值**（过早共识） | 0.35 | 0.25 / 0.45 | 检测灵敏度 |
| **δ 自适应阈值 base** | 各 δ 基线 | ±20% | v6 诊断 |
| **影响系数**（INFLUENCE_IMPACT_*） | 0.4/0.2/0.5/0.6 | ±30% | 旧路径信念更新 |

## 2. 实验设计

- **任务**：Crisis（困难，治理空间大）+ Supplier（简单，天花板对照）
- **条件**：固定 seed（42、123、456 各 N runs），`full` 治理条件
- **对照**：基线参数（当前）vs 每个消融值
- **每点 runs**：3 seeds × 5 runs = 15 runs
- **指标**：
  - τ 均值/方差（决策质量）
  - 治理效果 d（full vs none）
  - 收敛轮数
  - 干预次数

## 3. 通过标准（不敏感判定）

| 指标 | 不敏感阈值 |
|------|-----------|
| τ 均值变化 | \|Δτ\| < 0.05 |
| 治理效果 d 变化 | \|Δd\| < 0.2 |
| 显著性方向不变 | 若基线显著，消融后仍显著（或方向一致） |

**若通过** → 可辩护"启发式参数不是性能瓶颈，结果对参数选择鲁棒"。
**若崩塌** → 需标定为关键参数，或从启发式转向可学习/可校准。
