## Part A：跑实验前可写的贡献

跑实验前，可写贡献分两层：

- **A 层**：已有真实实验数据支撑的发现（169 closed-loop runs + Fraud 系列 38 runs + 跨模型 30 runs），可以直接写入论文，只需按证据强度诚实标注。
- **B 层**：框架/方法论设计（代码已实现、单元测试通过，但未经正式实验验证），只能作为"系统设计与方法论"章节书写，**不能**包装成实证结果。

### A 层：已有实证证据支撑的发现（可直接写入论文）

#### A1. 共识-质量弱相关（探索性观察）

| 项 | 内容 |
|---|---|
| 发现 | 群体共识度 R 与决策质量 τ 跨任务弱负相关：**r = -0.10，p = 0.20（不显著）**（N=169，Crisis 80 + Supplier 89） |
| 意义 | 对 DeGroot 模型"收敛 = 正确"的隐含假设的经验质疑——共识水平不是正确性的可靠代理 |
| 证据强度 | ★★★☆☆（探索性观察，p 不显著，必须标注） |
| 论文位置 | Introduction / Discussion 的 motivation 或"发现 1" |
| **可写程度** | **现在可写**，但只能作为探索性观察，不能作为"发现" |

> ⚠️ 诚实红线：这是项目审计中最大的过度声明风险点（§26.1 曾因此被修正）。任何书写必须带 "(p=0.20, not significant)"。

#### A2. 结构性信息重排 vs 程序性治理（F2，最强实证）

| 项 | 内容 |
|---|---|
| 发现 | Crisis 任务：shuffle（打乱知识依赖图，零 LLM 干预）d=**1.44**（p<0.001）显著优于 full 治理 d=**0.92**（p=0.0038） |
| 边界 | Supplier 任务 shuffle d=0.09（p=0.78）——天花板效应（基线 τ=0.68）下结构性重排失效 |
| 意义 | 信息流拓扑是决策质量的主要决定因素，程序性干预次之；治理效果**任务依赖** |
| 证据强度 | ★★★★☆（n=24/cell，p<0.001，单模型 DeepSeek） |
| 论文位置 | 核心实证发现之一 |
| **可写程度** | **现在可写**，且这是论文的骨架性证据 |

> 这条发现的张力：它既是"治理有效"的证据（full 显著优于 none），又是"治理并非最优手段"的证据（shuffle 更强）。这个张力本身就是论文叙事——**测量与诊断的价值可能大于干预的价值**（与"测量先行，治理在后"的策略一致）。

#### A3. 干预策略选择决定治理成败（E9 smoke test 系列）

| 项 | 内容 |
|---|---|
| 发现 | 同一治理框架下：破坏性干预（reduce_weight + force_reflection）Δτ = **-0.267**；非破坏性干预（inject_evidence + rebalance_attention）Δτ = **0.000**（N=6，2026-07-25 重跑实测；历史 +0.533 未复现） |
| 意义 | "改变信息流向而非信念权重"是可行的设计原则；破坏性干预（压制/强制反思）不仅无效而且有害（F3 反向强化 +0.94、F5 依赖链误伤） |
| 证据强度 | ★★☆☆☆（smoke test，N=6） |
| 论文位置 | 方法章节的"设计原则" + Discussion 的边界条件讨论 |
| **可写程度** | **现在可写**（作为设计演进故事与边界条件），但**不能**声称非破坏性干预有效 |

#### A4. 旧路径 R/T/H 强耦合负面发现（§27.1，方法论贡献）

> ⚠️ **路径区分（2026-07-31 核实）**：R/T/H 强耦合是**旧 asyncEngine 路径**（scalar beliefs，r=0.9175）的实证发现。v6 新路径（MeasurementLayer）已在代码层面修正（见 B4），旧路径已 `@deprecated`（TerminationDecider 标注 deprecated for v6，仅 fraud 系列向后兼容）。本发现作为"旧测量路径的边界刻画"仍有发表价值，但**不再是当前框架的现状**。

| 项 | 内容 |
|---|---|
| 发现 | 旧 asyncEngine 路径（scalar beliefs）上 R/T/H 是"同一轮信念分散度"的不同变换：R-T r=**-0.967**、R-H r=-0.667、T-H r=0.758（N=259）；旧 F=(1-R)+T·H ≈ 0.019 + 2.014·(1-R)（R²=0.955），F 几乎是 (1-R) 的线性变换（双重计数） |
| 意义 | **MAS 小群体与物理系统的本质差异**：物理中 R/T/H 是独立热力学变量，基于 scalar beliefs 的 MAS 度量中 DeGroot/FJ 信念更新让"对齐"与"收敛"同步发生 → 旧"3 维热力学状态空间"叙事不成立；**正是这一发现驱动了 v3.2.1 的 MeasurementLayer 重写** |
| 证据强度 | ★★★★★（N=259，代码事实 + 统计确认） |
| 论文位置 | 方法学贡献 / 测量路径演进的动机与负面发现 |
| **可写程度** | **现在可写**，但必须与 B4（新路径已解耦）成对呈现——"旧路径耦合实证 + 新路径解耦设计"是完整的测量演进故事 |

### B 层：框架与设计贡献（只能写"设计"，不能写"实证"）

以下内容代码已实现、单元测试通过，但**没有正式实验数据**。只能作为"系统设计/方法论"书写，或者作为"待验证设计"提出。**把 B 层写成实证结果是本项目最大的诚信风险**（§26 审计教训）。

#### B1. 5 维认知状态设计（Utility / Evidence / Inertia / Confidence / Susceptibility）

- **内容**：从 agent 结构化输出（itemBeliefs/evidence/confidence）确定性计算 5 维状态，**零额外 LLM 成本**；区分于旧 scalar belief 的语义模糊（§27.2）
- **硬约束**：Evidence 维度强依赖"预定义选项"，开放任务失效；Utility 在开放讨论/数值任务退化（§27.3 场景泛化表）
- **可写程度**：设计章节**现在可写**；"5 维状态真实有效"的实证 claim 需 E1-E8（尤其 E1 稳定性、E6 解耦、E7 检测器准确率）

#### B2. 8 个 δ 一致性诊断（polarization / oneDMask / evidenceSilence / confidenceGap / stanceFlip / noResponse / concentration / consistency）

- **内容**：基于认知状态的一致性诊断信号，**无需 ground truth 标注**（对比旧检测器需要人工标注偏差场景）；确定性、逐轮、零成本
- **意义**：oneDMask（标量共识掩盖向量分歧）、evidenceSilence（证据被系统性忽视）、confidenceGap（自报信心与效用位置矛盾）等信号解决了旧检测器的结构性问题
- **硬约束**：δ 触发率偏高（Pilot A 组 45% / B 组 40%，目标 [5%,30%]）；阈值需校准
- **可写程度**：设计 + 单测**现在可写**；"δ 诊断精准"实证 claim 需 E9 V6

#### B3. 非破坏性干预原则（inject_evidence + rebalance_attention）

- **内容**："改变信息流向，而非信念权重"；inject_evidence 注入被忽视的私有证据、rebalance_attention 重排发言顺序让被忽视者先发言
- **可写程度**：原则**现在可写**（配 A3 的破坏性 vs 非破坏性对照故事）；有效性 claim 需 E9 V6（H9）

#### B4. MeasurementLayer 的 F = U - T·H 修正自由能（新路径，已解耦）

- **代码现状（2026-07-31 核实）**：MeasurementLayer v3.2.1 将 R/T/H 全面重写——R = Utility 向量平均 cosine（空间对齐）、T = Utility 逐轮 L2 距离（时序波动）、H = Evidence supports 分布熵（信息结构），三者来自**不同信息源**（[MeasurementLayer.ts:227-254](file:///c:/Users/TEMP.LAPTOP-38M7FOD7.000/Desktop/swarmalpha/src/lib/thermodynamics/MeasurementLayer.ts#L227-L254)）；F 改为 F = U - T·H（亥姆霍兹形式）。**这是对 §27.1 旧路径强耦合的代码级修正**，旧路径已 `@deprecated`
- **实证验证现状（必须诚实）**：r=0.274 的解耦验证来自 [`analyze_social_thermodynamics.ts`](../../experiments/v2/analyze_social_thermodynamics.ts) 对 207 runs（870 round-observations）的真实数据分析（THEORY.md §0.1 验证 3：sync r=-0.046 近正交、fraud 38 runs r=-0.271；旧 r((1-R),T·H)=0.917 双重计数确认）。**但该脚本的 U=L1 范数、T=sampleStd、S=熵仍基于 scalar beliefs 的变换**，与 MeasurementLayer 的 utility 向量实现不是同一变量——native 模式（LLM 直接输出 cognitiveState）下三变量的独立解耦验证**仍待 E9 V6 真实数据**
- **可写程度**：方法设计 + scalar 近似验证**现在可写**；"MeasurementLayer 新实现真实数据解耦"的实证 claim 需 E9 V6

#### B5. 审计基础设施（SHA-256 manifest / detectionMetrics / parameters / effectMetrics）

## Part C：future.md 路径上限与价值评估（只考虑硬约束）

### 评估方法：什么是"硬约束"

本部分**不考虑**实现难度、时间、API 预算、算力、人力（这些是工程约束）。只考虑**科学层面的硬约束**——由已有证据或理论要求强加、无法通过工程绕过的限制：

1. **已有实证证据**：§27 强耦合（N=259）、F1-F16、Pilot 数据、smoke test 数据
2. **理论成立的最低条件**：该方向声称的核心命题，其数学/统计前提是否被已有证据满足（如"正交性""马尔可夫性""可证伪性"）
3. **学术诚信约束**：能否在不夸大、不重新包装已证伪概念的前提下成立
4. **竞争格局**：与已发表工作的逻辑距离（是否已被抢占、是否正交）

**核心事实库（评估基准）**：

| 事实 | 数值 | 影响 |

| 旧路径 R/T/H 强耦合（scalar beliefs） | R-T r=-0.967，旧 F≈(1-R) 线性（R²=0.955） | **仅约束旧 asyncEngine 路径**（已 @deprecated）；它驱动了 MeasurementLayer 重写，不再是当前框架现状 |

### 五条战略路径

#### 路径一：Web3 / 区块链 + 多智能体治理

- **核心卖点**：实时热力学影响力量度 vs 事后 Shapley；可 ZK 验证的治理信号
- **硬约束清单**：
  1. **测量 ≠ 影响力**：R/T/H 是群体统计量，不含因果关系（谁影响了谁）。用 R/T/H 做"影响力量化"存在语义鸿沟——正是 F14 揭示的"识别-干预断裂"的镜像问题。这条路径声称的影响力恰恰是项目**测量不了**的东西
  2. **多信号问题部分缓解**：旧路径下 R/T/H 强耦合（r=-0.967）使"三维信号"缩水为单信号；v6 新路径已解耦（utility cosine / utility L2 / evidence 熵，scalar 近似验证 |r|<0.3）——若 native 解耦被 E9 V6 确认，"三维信号上链"的技术前提恢复。但 web3 的核心价值不在信号数量，而在**测量的因果有效性**（见约束 1），该约束不受解耦影响
  3. **竞争正交性存疑**：DAO-Agent（深圳大学）已用 Shapley+ZKP 做贡献度量。本项目若只上链"共识/失序度"，与 DAO-Agent 的正交性消失（都是"度量+上链"）
- **学术上限**：中。本质是"把已有度量工程化上链"——学术增量是应用层，不是科学层。上限为顶会 workshop / 系统论文
- **价值**：叙事价值 > 学术价值。作为"项目愿景"吸引合作者有效，作为独立论文竞争力弱
- **判定**：**受限**。除非剥离热力学包装、只以"可证明的实时共识/失序度"为原语（放弃"影响力"claim），否则硬约束直接否决核心卖点

#### 路径二：社会状态监测 / 社会热力学作为监测层

- **核心卖点**：R/T/H/F 作为智能体社会的"宏观经济指标"，支持比较治理实验
- **硬约束清单**：
  1. **监测层不要求变量正交**——GDP 的分项也相关，描述性仪表盘允许指标冗余。§27 强耦合不构成否决
  2. **跨模型语义稳定性是风险**：F15 显示同样变量在不同模型行为下含义不同（Qwen 走捷径时"共识"是真实共识还是捷径伪共识？）；F16 显示跨模型结论需控制代码版本。监测层的 claim 需跨模型一致性证据
  3. **"比较治理实验"依赖治理有效性**：若 H9 不显著，监测层退化为"观测报告"（描述性价值仍在，行动价值缺失）。但监测-预警价值可独立于治理成立（如临界减速预警）
  4. **需求真实**：THE HERD（150 万 agent 无治理趋同崩溃）证明监测需求是真实的，且无人提供热力学监测层——空白真实
- **学术上限**：高。若配规模化证据（数百 agent）可到 NeurIPS/ICML 级别的系统级贡献；核心是"运行时健康监测 + 预警"范式
- **价值**：高。与现有 169 runs 数据兼容（posthoc 可算）、自然延伸、空白真实
- **判定**：**可行（最优路径）**。硬约束不否决任何核心 claim；唯一要求是诚实标注"描述性指标，非因果测量"

#### 路径三：A2A 协议治理层扩展

- **核心卖点**：Governance Card 标准化——Agent Card 的配套组件，暴露认知状态 + 治理能力
- **硬约束清单**：
  1. **CSI 通用性 vs Evidence 场景依赖**（§27.3）：声称"任何智能体暴露内部认知状态"需要一个通用 schema，但 Evidence 在开放任务失效、Utility 在数值任务失效——**通用标准只可能是"最小核心集"（Inertia/Confidence/Susceptibility + 可选维度）**，这会削弱"5 维完整"的叙事
  2. **自报状态的对抗可信度**（F14）：治理服务商信任 agent 自报的认知状态——恶意 agent 可伪造（F14 已实证）。标准化提案必须包含对抗考虑，否则标准有根本缺陷
  3. **标准化提案无科学发现**：这类工作的学术价值在"被采纳"，审稿价值有限（通常 arXiv + 系统类会议）
- **学术上限**：中高（基础设施级影响力——若 A2A 生态成熟，引用潜力大），但**非科学发现**
- **价值**：高（空白真实、与 A2A 直接互补、适合作为"应用落地点"叙事）
- **判定**：**条件可行**。限定为"排名任务场景的认知状态接口（最小核心集）+ 对抗性声明"，作为第二/三篇论文或技术报告；不依赖新实验即可开始写

#### 路径四：越狱检测（基于认知一致性）

- **核心卖点**：行为驱动而非内容驱动的越狱检测——认知状态一致性，零成本
- **硬约束清单**：
  1. **自报式认知状态被自身证据否决**：F14 断裂 3 实证——恶意 agent 主动提供误导性 evidence、主动引用他人、保持 rank-belief 一致，FM-2.4/2.5/2.6 零触发。**让骗子填自我评估表测不出骗子**，这是检测前提的根本违反
  2. **F10 直接打击核心信号**：治理开后恶意 agent 言行一致性反而上升（0.764 vs 0.610）——"言行一致性"这个最强行为信号在对抗场景下区分力下降
  3. **F11/F12 打击整体区分力**：单点恶意对齐分与诚实无差异（-0.013）；治理开 vs 关的防御价值不显著（p=0.689）
  4. **唯一出路违背卖点**：要恢复检测力需引入 LLM 语义交叉验证（F14 修复方向 1），但那正是"内容驱动"——回到 PANDAGUARD 等已拥挤的赛道，且失去零成本优势
- **学术上限**：低（在本项目框架内）。方向本身真实（多智能体越狱是真实威胁），但本项目的检测器路径被自己的实证证据链否决
- **价值**：中（需求真实，但需要根本性重构——这不是工程问题，是硬约束问题）
- **判定**：**被否决（本项目框架下）**。除非彻底重构为 LLM 语义检测（放弃零成本卖点 + 进入拥挤赛道），否则不建议投入

#### 路径五：最小干预治理 / token 效率

- **核心卖点**：零成本数学检测 + 稀疏干预 → 最大 token 效率；"治理即信息论优化"
- **硬约束清单**：
  1. **治理有效性证据不足**：Δτ=0.000（N=6）——"治理提升决策质量"不成立。**但 claim 可安全转为"不损失质量 + 显著降本"**：Δτ≈0 意味着治理干预既不帮助也不伤害，在此前提下 token 节省是纯收益。这是叙事转变，不违反证据
  2. **F2 是这条路径的实证基石**：结构性干预（shuffle，零 LLM token）d=1.44 优于程序性治理 d=0.92——"更少的干预/计算反而是更好的决策"已被数据支持
  3. **F8 支撑 token 故事**：失败组 token 是成功组 2.9 倍——token 消耗与治理结果相关
  4. **竞争正交**：Optima/MARS/Agent-GSPO 从训练/架构切入通信效率；本项目的切入点是"数学监测决定何时用 LLM"——正交
- **学术上限**：高。可与理论方向二（率-治理理论）结合形成"可证明的效率界"；独立即可做"最小干预协作范式"实证论文
- **价值**：高（token 成本是真实痛点，现有数据部分支持，且与 A3/F2 证据自然衔接）
- **判定**：**可行（第二优先）**。硬约束要求：叙事从"提升质量"改为"维持质量 + 降本 + 结构优于程序"；H9 显著则为加分项而非必要项

### 八个理论方向

#### 方向一：社会相变理论（临界指数 / 普适类 / 临界减速）

- **硬约束清单**：
  1. **旧路径的致命约束已解除**：scalar 路径 R-T r=-0.967（序参量-控制参数共线）曾否决相变分析——但该路径已 `@deprecated`，v6 新路径（MeasurementLayer）的 T 已是真实时序波动（utility 逐轮 L2 距离）、R 是 utility cosine，序参量与温度在**定义层面已解耦**（scalar 近似验证 r(U,T×S) 跨任务 <0.3）
  2. **已有负面发现须诚实引用**：THEORY.md §0.1 验证 2 在 207 runs scalar 数据上**未发现临界涨落**（σ²(b) 随 R 单调递减无峰值，治理触发不是相变临界点）——这预示相变分析在 LLM agent 群体上可能得到"非相变"的诚实结论（本身是负面发现）
  3. **native 模式解耦验证先行**：相变分析建立在 MeasurementLayer 新测量之上，native 真实数据的独立解耦验证（E9 V6 附带产出）是启动前提
- **学术上限**：极高（统计物理 × AI 的跨学科桥梁——若做成，"计算社会物理学"成立）
- **价值**：高（理论诱惑力最大）
- **判定**：**条件可行**（由"受限"上调）。旧路径障碍已随 MeasurementLayer 重写解除；前提是 (a) E9 V6 确认 native 解耦、(b) 接受"无相变"的负面发现风险——但这风险本身是 THEORY 验证 2 已铺垫的诚实结论

#### 方向二：治理最小干预原理（率-治理理论 / Lyapunov 自愈条件）

- **硬约束清单**：
  1. **不依赖 R/T/H 正交**——只需要一个有效状态变量（R 单独即可，或承诺度 δ=|b-ι|，或 5 维任意子集）。§27 不构成否决
  2. **可形式化的动力学**：DeGroot/FJ 信念更新是显式线性动力学，可做最优控制分析；δ=|b-ι| 是 169 runs 现成可算的
  3. **现实偏离需承认**：LLM agent 实际行为偏离 DeGroot（F15 捷径、锚定效应）——"可证明界"需在"简化模型 + LLM 验证"双层结构下声明
  4. **竞争空白真实**：所有现有治理都是启发式（"加检测器，设阈值"），无人提出"最少必要治理量"
- **学术上限**：**极高（第一个可证明界）**——如果成功，是领域理论基石
- **价值**：极高（无人提出过 + 与路径五天然衔接）
- **判定**：**可行（理论方向中最优）**。与 v0.4 承诺度框架（THEORY.md）直接衔接；不需要新实验即可开始理论工作，用现有数据验证

#### 方向三：信-热统一理论（Landauer / Jarzynski / 涨落-耗散）

- **硬约束清单**：
  1. **"F 非自由能"否决点已消除（部分）**：旧 F=(1-R)+T·H 已被证明是 (1-R) 的线性变换（双重计数），用它推导 Jarzynski 类比 = 包装已证伪概念——该风险随 v6 新路径 F=U-T·H（真实亥姆霍兹形式）落地而消除
  2. **剩余硬约束——等温/准静态前提**：Jarzynski 等式与涨落-耗散定理要求系统处于热浴（等温）和（近）平衡态。MAS 讨论既不等温也无热浴，U/T/S 仍是启发式映射而非真实热力学量——类比框架可以写，但"推导"会被统计物理审稿人质疑
  3. **验证基础待建**：scalar 近似分析（THEORY §0.1）确认 F 形式解耦，但 native 模式的 U/T/S 真实语义（utility/时序/evidence 熵）尚未在实验数据上验证——热力学恒等式的实证映射需要 E9 V6 后的数据
- **学术上限**：极高（理论优雅度顶级）
- **价值**：高（跨学科吸引力）
- **判定**：**受限（由"否决"上调）**。概念基础（F=U-T·H）已不再是障碍，但等温/准静态前提与"启发式映射 vs 真实热力学量"的鸿沟仍在——定位为"类比框架 + 明确的边界声明"，不可声称严格热力学推导；启动前提同样是 native 解耦验证

#### 方向四：认知状态接口（CSI 标准化）

- **硬约束清单**：同路径三——Evidence 场景依赖限制通用性；对抗可信度（F14）需处理；无科学发现（标准化提案性质）
- **学术上限**：中（基础设施级，被采纳则高引用，审稿上无理论深度）
- **价值**：中高（与路径三同源）
- **判定**：**条件可行**（最小核心集 + 排名任务限定 + 对抗性声明）

#### 方向五：影响力级联理论（渗流阈值 / 超级传播者 / 接种策略）

- **硬约束清单**：
  1. **影响力边推断不可靠**：H10（影响力图与影响力管理器不一致）、F5（依赖链误伤）显示图结构存在缺陷；F15 显示在"信息捷径"场景下影响力网络可以是空的（a2-a5 共享率 0-16%，agent 之间没有真实影响，级联分析的对象不存在）
  2. **级联需要因果或至少强时间序**：观测到的"影响力"可能只是共同锚定（Pilot 锚定效应）或任务结构伪影
  3. **正面用途**：级联检测本身可作为诊断——"检测影响力是否真实存在"（区分真实传播 vs 捷径伪共识）
- **学术上限**：中高（网络科学成熟，LLM 场景新）
- **价值**：中（应用价值高，理论增量有限）
- **判定**：**受限**。需先解决"影响力边推断的可靠性"（这是测量问题，不是工程问题）；作为诊断工具（检测伪影响力）有独立价值

#### 方向六：认知均衡理论（自由能景观 / 多重稳态 / 遍历性破缺）

- **硬约束清单**：
  1. **F 退化问题已缓解**：旧 F ≈ (1-R)（线性变换）曾使"自由能景观"退化为"共识景观"；v6 新路径 F=U-T·H 是 5 维认知状态的真函数且已解耦（scalar 近似验证 |r|<0.3）——"自由能景观"在定义层面重新成立。⚠️ 但 T/S 的 utility/evidence 语义（vs scalar 近似）仍需 E9 V6 验证
  2. **部分可挽救**：Kuramoto 模型确有双稳态（极化 / 共识）——"系统被困在坏均衡（极化/虚假共识）"是可研究的问题，且 A1（共识≠质量）提供了"好/坏均衡"区分的动机
  3. **马尔可夫性存疑（剩余硬约束）**：LLM agent 动力学强上下文依赖，均衡分析的数学工具（不动点/遍历）适用性有限——需在"承诺度 + FJ"简化模型上做，LLM 系统做实证验证
- **学术上限**：极高（理论深度最大方向之一）
- **价值**：高
- **判定**：**条件可行**。条件：在"承诺度 + FJ"简化模型上做形式化（与方向二共用框架），LLM 系统作实证验证；F=U-T·H 提供景观函数，δ=|b-ι| 提供均衡分类特征

#### 方向七：熵-效用权衡原理（帕累托前沿）

- **硬约束清单**：
  1. **现有数据暗示权衡可能很弱（旧路径）**：R 与 τ 弱相关（r=-0.10），而旧路径 H 与 R 强相关（r=-0.667 至 -0.967）→ H 与 τ 也弱相关——**在旧参数空间内，多样性不牺牲质量**（"探索与利用在 MAS 中不冲突"的候选发现）
  2. **⚠️ H 语义已变**：新路径 H=evidence supports 熵（信息结构多样性），与旧 H（beliefs 分布熵）不是同一变量——上述"权衡弱"结论基于旧数据，新路径下 H-τ 关系**需重新测量**（E9 V6 附带产出）
  3. **帕累托前沿刻画可行**：确定性引擎 + 可复现 PRNG，参数扫描（检测阈值/干预强度/频率）是纯计算工作，硬约束满足
  4. **证伪机会**：若扫描后确实存在前沿 → 设计原则级贡献；若不存在 → "MAS 无熵-效用权衡"的负面发现（同样有价值）
- **学术上限**：高（若是真约束 = 设计原则，类比热力学第二定律的叙事地位）
- **价值**：高（与 A1 证据自然衔接）
- **判定**：**可行（探索性）**。现有数据不构成否决，反而提供动机；需参数扫描实验（介于分析与实验之间）

#### 方向八：集体认知共振理论

- **硬约束清单**：
  1. **形式化困难**：共振要求"驱动频率匹配固有频率"——需要把讨论节奏（发言频率/轮次间隔）形式化为频率参数，并存在"固有频率"概念。LLM agent 无物理固有频率（除非把发言意愿/DeGroot 学习率当作，但这是隐喻）
  2. **操作化依赖 R/T/H（新路径下部分缓解）**：共振的操作标准（"R 快速上升同时 H 非零"）——旧路径下 R/H 强相关（r=-0.667），"R 上升 H 保持"难以独立控制；v6 新路径 H=evidence 熵与 R=utility cosine 来自不同信息源，操作化前提改善，但仍需 native 验证
  3. **高伪证风险**：容易退化为"比喻而非理论"——"给秋千施加匹配的推力"缺乏可度量的共振峰
- **学术上限**：中高（若严格化，新视角独特）
- **价值**：中（概念吸引人）
- **判定**：**受限**。严格化门槛高；作为论文主方向风险大，可降级为讨论节奏实验（发言顺序/间隔的消融）中的解释性视角——这不需要"共振"理论成立

### 路径优先级综合判定

**判定标准**：只按硬约束下的学术上限与价值排序（不含工程工作量）。

| 排名 | 路径/方向 | 硬约束判定 | 学术上限 | 价值 | 与现有工作的衔接 |
|---|---|---|---|---|---|
| 1 | **方向二 治理最小干预原理** | 可行 | 极高（第一个可证明界） | 极高 | 与路径五、v0.4 承诺度框架天然衔接 |
| 2 | **路径五 最小干预治理** | 可行 | 高 | 高 | 直接复用 A2/F2/A3/F8 证据；叙事转变即可 |
| 3 | **路径二 社会状态监测** | 可行 | 高 | 高 | 与 169 runs 数据兼容；最优扩展 |
| 4 | **方向七 熵-效用权衡** | 可行（探索性，H 语义已变需重测） | 高 | 高 | 与 A1 衔接；参数扫描即可启动 |
| 5 | **方向六 认知均衡** | 条件可行（弃旧 F 用 R/承诺度） | 极高 | 高 | 与方向二共用简化模型框架 |
| 6 | **方向一 社会相变** | 条件可行（native 解耦验证先行） | 极高 | 高 | 依赖 E9 V6 解耦验证结果；THEORY 验证 2 已有"无临界涨落"铺垫 |
| 7 | **路径三 A2A 治理层** | 条件可行（最小核心集） | 中高 | 高 | 无新实验依赖，可先写提案 |
| 8 | **方向四 CSI** | 条件可行 | 中 | 中高 | 与路径三同源 |
| 9 | **方向五 影响力级联** | 受限（边推断不可靠） | 中高 | 中 | 可作为"伪影响力检测"诊断工具 |
| 10 | **方向八 认知共振** | 受限（形式化难） | 中高 | 中 | 降级为讨论节奏消融的解释视角 |
| 11 | **方向三 信-热统一** | 受限（等温/准静态前提 + 映射鸿沟） | 极高 | 高 | 概念基础 F=U-T·H 已落地；定位为类比框架 |
| 12 | **路径一 Web3** | 受限（测量≠影响力） | 中 | 中 | 叙事价值 > 学术价值 |
| 13 | **路径四 越狱检测** | **否决（自报状态被 F14/F10 否决）** | 低 | 中 | 需根本性重构才可考虑 |

**综合结论**：

1. **治理有效性（E9 V6 H9）是全局瓶颈**：方向二、路径五、路径二的上限都间接依赖治理有效性的证据强度。E9 V6 之前，所有"治理"方向的论文都只能以"设计 + 边界条件"呈现。
2. **最被低估的是方向二（率-治理理论）**：它不依赖治理实验的正面结果（在简化模型上可证明界，LLM 系统作验证），学术上限最高且无硬约束障碍——与项目当前的"测量 + 负面发现"定位高度兼容。
3. **最该避免的是路径四**：被自己的实证证据否决（F14/F10/F12 证据链表明自报认知状态在对抗场景下不可信）；其次是方向三（概念基础已修好，但等温/准静态前提与"启发式映射 vs 真实热力学量"的鸿沟使其只能定位为类比框架，投入产出比低）。
4. **硬约束不否决任何"测量/诊断"型方向**：旧路径强耦合负面发现（A4）证明"负面发现"本身有发表价值——路径二、方向七即使治理无效也成立。
5. **新路径解耦已落地，改变了多个方向的评估**：R/T/H 耦合的硬约束从"全局现状"降级为"旧路径历史"（A4/B4 成对呈现）；方向一（社会相变）从受限升为条件可行、方向三（信-热统一）从否决升为受限、路径一（Web3）的多信号障碍部分解除。**遗留的唯一实证缺口是 native 模式（LLM 直接输出 cognitiveState）下的独立解耦验证——这正是 E9 V6 附带产出可以关闭的缺口**。
6. future.md 的乐观评估（路径二"低风险"、路径五"低-中风险"）与硬约束评估一致；**其"路径四 中-高风险"的评估偏乐观**——硬约束下它是"否决"而非"风险高"。
