# V6 False-Consensus Detector Screening

**假共识（证据复用 + 对齐）预测翻车；分歧反而轻微保护。exactReuseFraction 是候选的真相盲翻车探测器。**

状态：FACT REPORT + CONTRIBUTION POSITIONING（DRAFT）— 只读分析，2026-08-15。零 provider，复用 5 轮 exchange 的 80 个无治理场。口径更正（2026-08-15）：`exactReuseFraction`（总 r=0.641、任务内 r=0.388）与 `maxPairwiseTV`（r=−0.349）为 80 场口径；其余候选量（对齐 R 等）仍为 64 场口径，80 场重算待做。

## 0. 结论（一句话）

在无治理（无干预）的 80 场里，**"证据精确复用率越高、群体对齐越高，最终 Brier 越差"**；而"分歧越大"反而略好。这指向一个**可审计的真相盲翻车探测器**：假共识（false consensus）——群体重复同几条证据并达成一致——是集体决策翻车的前兆，且可用内容哈希精确测量。

## 1. FACT — 探测器筛选（候选量 vs 最终 Brier）

| 候选量 | 相关 r | 方向 |
|---|---|---|
| **证据精确复用率 exactReuseFraction** | **+0.641** | 复用越高 → 越翻车 |
| **对齐 R** | **+0.565** | 越一致 → 越翻车 |
| argmax 投票集中度 | +0.458 | 越一边倒 → 越翻车 |
| pooled top-two 差距 | +0.372 | 越自信 → 越翻车 |
| **最大分歧 maxPairwiseTV** | **−0.349** | 越分歧 → **越不翻车** |
| 报告确信度 | −0.161 | 弱 |
| 逐字覆盖 / 覆盖缺口 | ±0.113 | 无预测力 |

- 中位数切分 exactReuseFraction（64 场口径，80 场待重算）：低复用（n=32）meanBrier **0.269**，高复用（n=32）meanBrier **0.861**。

## 2. FACT — 任务内检验（排除任务难度混杂）

| 层面 | r |
|---|---|
| 总相关 | 0.641 |
| 任务间（任务均值）| 0.785 |
| **任务内（控任务后偏离）** | **0.388** |

- 任务内 r=0.388 仍为正且可观：**同一任务内，复用率更高的场 Brier 也更高**。探测器不是"难任务"的单纯代理。
- 逐任务印证：reuse 最高 task39（0.437）→ Brier 1.572；reuse 最低 task54（0.063）→ Brier 0.008。

## 3. INFERENCE — 假共识签名

- "翻车"的可观测前兆不是"分歧"，而是**"证据重复 + 对齐"**：群体反复引用同几条证据、概率向量趋同 → 假共识 → 一起自信地错。
- "分歧"在本数据中是**轻微保护**（多元观点 → 更少翻车）。这与 earlier exchange 发现一致：supports 干预是把"健康的分歧"放大成灾难，而非分歧本身有害。
- 这解释了 0.8 分歧阈值的漏检：真正翻车的是"分歧小但证据重复"的假共识场，恰好落在阈值之下。

## 4. LIMITATION

- n=80 但仅 8 任务（聚类）；任务内 r=0.388 基于每任务 10 场的小样本。
- `exactReuseFraction` 只识别**逐字**重复（内容哈希相等），不改写/同义重复。
- 仅 DeepSeek deepseek-chat、temperature 0、HiddenBench 8 任务、单一 prompt。
- 相关 ≠ 因果；本报告是探测器**筛选**，非已验证的 detector。

## 5. 贡献定位（vs arXiv 前沿，DRAFT）

### 5.1 已存在（不能主张为新）

- "隐藏档案 → 群体失败、分享独特信息有效"：[Stasser & Titus 1985] 经典结论。
- "信息分散时多 agent LLM 掉到 ~30%"：[HiddenBench (arXiv 2505.11556)](https://arxiv.org/pdf/2505.11556v2) —— 本项目用的正是它。
- "多 agent 辩论在确定答案任务上常不优于单 agent"：[CHAL (2605.12718)](https://ar5iv.labs.arxiv.org/html/2605.12718)。
- "共识是否真实"的**耦合增益 + 有效性诊断**：[When Is Emergent Consensus Real? (2606.22203)](https://arxiv-org.ezproxy.obspm.fr/html/2606.22203v1) —— 最贴近，但用**相关性 + bootstrap**，非哈希级审计。
- "分布式信息下的系统性失败模式"：[ICML 2026 poster](https://icml.cc/virtual/2026/poster/62206)。

### 5.2 我们的空位（HYPOTHESIS，未建立）

前沿的"共识有效性诊断"靠**输出相似度 + 相关性**；我们的工程底座能做**更硬、可重放**的版本：

1. **哈希级"证据耦合"测量**：`exactReuseFraction` = 1 − 不同内容哈希数/引用总数，逐字精确、可重放、真相盲，而非模糊的输出相似度。
2. **干预闭环**：从"测出假共识"推进到"对假共识场投证伪证据 → 审计救回"（前文 attacks 披露已显示该机制可行，Brier 0.090，n=30）。
3. **可审计性**：truth 防火墙 + 重放 + 出处，使"翻车探测器"本身可被独立证伪。

### 5.3 主张（DRAFT，用于定论文方向）

> 论文贡献不是"治理有效"，而是**把"群体共识是否真实"从相关性诊断升级为哈希级、可审计、真相盲的测量（证据复用），并证明它预测翻车（任务内 r=0.388）、且可驱动针对性干预（披露被压制的证伪证据）**。
